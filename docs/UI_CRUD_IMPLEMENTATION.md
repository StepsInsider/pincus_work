# Pincus Work – UI und Modul-CRUD

Die aktuelle Feature-Branch-Version bringt die Oberfläche näher an die bereitgestellte Pincus-Referenz und aktiviert die vorhandenen lokalen Drift-Tabellen für die Bedienung.

Funktionsumfang:
- responsive grüne Kopfzeile und weiße Seitennavigation
- Pincus-Branding und dezentes Baum-Wasserzeichen
- responsive Dashboard-Karten
- Datensätze anlegen, bearbeiten und löschen in Baustellen, Kunden, Aufträgen, Mitarbeitern, Zeiterfassung, Berichten, Material und Maschinen
- Datum- und Uhrzeit-Picker in Formularen
- Aktualisieren per Refresh und direkte Navigation über Dashboard-Karten
- vorhandenes Drift-Schema weiterverwendet; keine neue Migration erforderlich
